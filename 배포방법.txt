창섭이 키우기 — 무료 배포 안내 (게임 파일 분리 버전)

중요: 사이트 파일과 게임 ZIP을 따로 올립니다.
- 이 폴더의 index.html, assets/, 배포방법.txt는 GitHub 저장소에 업로드합니다.
- 게임 ZIP은 GitHub Releases에 업로드합니다. 브라우저에서 저장소에 올리는 파일은 25 MiB 제한이 있기 때문입니다.

1) 저장소 이름은 changseob-game 으로 만드세요.
2) 사이트 파일(index.html, assets 폴더, 배포방법.txt)을 저장소 최상위에 업로드합니다.
3) 저장소의 Releases → Create a new release를 누릅니다.
4) 태그 버전에 v1.0.0을 입력하고 제목은 창섭이 키우기 v1.0.0으로 지정합니다.
5) 게임 원본 ZIP을 첨부 파일로 올리기 전에 파일 이름을 changseob-game.zip 으로 바꿔 업로드합니다.
   - 원본 게임 ZIP은 별도로 보관하세요.
   - Releases 업로드에서 25MB 오류가 나면 GitHub CLI를 사용하는 방법이 필요할 수 있습니다.
6) Publish release를 누릅니다.
7) index.html 파일에서 YOUR-USERNAME을 실제 GitHub 사용자 이름으로 바꿉니다.
   다운로드 링크 형식:
   https://github.com/YOUR-USERNAME/changseob-game/releases/latest/download/changseob-game.zip
8) 수정한 index.html을 저장소에 다시 업로드/commit합니다.
9) Settings → Pages → Deploy from a branch → main → /(root) → Save로 배포합니다.

참고
- GitHub 브라우저의 일반 저장소 파일 업로드는 파일당 25 MiB 제한이 있습니다.
- Releases는 배포 파일을 코드 저장소와 분리해 배포하는 용도입니다. GitHub의 파일 업로드 화면에서 Release asset 업로드도 25MB 경고가 계속 나오면 GitHub CLI 등 별도 방법으로 업로드해야 할 수 있습니다.
- 게임은 Windows 실행 파일이며 브라우저에서 직접 실행되는 게임은 아닙니다.
