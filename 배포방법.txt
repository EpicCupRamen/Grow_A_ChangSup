창섭이 키우기 사이트 배포 안내

폴더 구성
- index.html : 사이트 메인 페이지
- assets/ : 페이지 미리보기 이미지
- games/창섭이_키우기.zip : 다운로드용 Windows 게임

무료 공개 방법 (GitHub Pages)
1. GitHub 계정으로 로그인하고 새 Public repository를 만듭니다.
2. 이 폴더 안의 site 폴더 내용(index.html, assets, games)을 저장소 최상위에 업로드합니다.
3. 저장소 Settings → Pages로 이동합니다.
4. Build and deployment에서 Deploy from a branch, Branch는 main, folder는 /(root)를 선택하고 Save를 누릅니다.
5. 배포가 끝나면 표시되는 주소로 사이트에 접속할 수 있습니다.

중요
- 게임 ZIP을 포함하므로 저장소와 배포 파일 크기를 확인하세요.
- 이 게임은 Windows 실행 파일(.exe)입니다. 웹브라우저 안에서 바로 실행되는 게임은 아닙니다.
- GitHub Pages는 정적 사이트 호스팅입니다. 사이트를 배포해도 다운로드 파일은 별도로 ZIP에 포함되어 있어야 합니다.
